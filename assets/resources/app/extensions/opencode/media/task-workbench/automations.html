自动化

按计划让 OpenCode 执行一段提示词。OpenCode 关闭时由 Windows 计划任务在到期时启动一次，完成后自动退出；平时不常驻任何进程。

跳过与失败的原因说明
missed_older错过多次，只补最近一次missed错过计划时间且超过宽限，按策略跳过install_moved计划任务触发时安装目录已不在原位置interrupted运行中途 OpenCode 被关闭timeout超过单次超时

只在至少有一个已启用的自动化时登记一个 Windows 计划任务（当前用户、一次性触发器，触发时间为最近一次到期时间）；没有已启用的自动化时会删除它。启动器位于 %LOCALAPPDATA%\OpenCode\automation-launcher，不在安装目录里，所以 OpenCode 关闭时可以随意移动安装文件夹；移动后启动一次 OpenCode 即可刷新路径。
